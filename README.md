# Dylan Guan 个人网站

这是一个无需安装依赖即可运行的静态个人作品集，包含：

- 首页三棱镜交互：悬停、键盘聚焦或触摸后，入射光、三束出射光和三个主题依次显现。
- 三个独立路由：`#/science`、`#/art`、`#/curiosity`。
- 响应式桌面/移动端布局、键盘可访问状态、减少动态效果偏好支持。
- 科学理性：学历与专利审查工作经历的内容卡片框架。
- 审美创造：视频作品横向展览、小红书入口、广告/品牌经历与合作品牌框架。
- 好奇心：岗位选题提案，以及书单、影单、兴趣框架。

## 本地预览

在本文件夹运行：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。
